# 评分权重的来源与调法

`data/character-weights.json` 里每个角色 8 个数，是权重评分用的「该角色吃哪条词条」：

| 键 | 对应词条 |
| --- | --- |
| `hp` / `atk` / `def` | 大生命 / 大攻击 / 大防御（小生命/小攻击/小防御按 0.1 量级折算到同一键） |
| `critRate` / `critDMG` | 暴击率 / 暴击伤害 |
| `em` / `er` / `heal` | 元素精通 / 元素充能效率 / 治疗加成 |

1 = 该词条对这个角色是满收益，0 = 完全不吃。评分公式是
`Σ(词条数值 × 官方系数 × 权重)`，只算副词条 + 理之冠主词条。

## 取值约定

实测量级对齐用的参照（同定位角色取同一套）：

| 定位 | 典型取值 |
| --- | --- |
| 双暴主 C | `atk 0.75, critRate 1, critDMG 1` |
| 精通反应 | `critRate 1, critDMG 1, em 1`，充能看循环 |
| 充能辅助 / 护盾 | `er 0.8~1`，护盾按生命或防御给 0.85~1 |
| 治疗 | `heal 1`，再叠生命或攻击 |

## 新角色怎么加

新版本上线后，出现下面两种情况时补这里：

1. 角色在列表里但评分是「通用」——说明权重表里没有它的名字
2. 角色在概览的等级分布里数得出来，但角色页打不开

加一行即可（键是**游戏内中文名**，不是 id）：

```json
"米提亚": { "hp": 0, "atk": 0.75, "def": 0, "critRate": 1, "critDMG": 1, "em": 1, "er": 0.2, "heal": 0 }
```

## 已知的估算项

| 角色 | 版本 | 依据 | 说明 |
| --- | --- | --- | --- |
| 米提亚 | 7.2 | 官方 7.2 更新说明：雷元素输出，靠星超导反应打伤害 | `em` 与双暴同权（1 / 1 / 1），充能给 0.2——如果实测她需要开大起手，把 `er` 提到 0.5 左右 |
| 瓦列里 | 7.2 | 官方 7.2 更新说明：雷元素辅助，提供增益与护盾 | 按「护盾吃生命」估计 `hp 0.85`；若实测吃防御，把 `hp` 与 `def` 对调 |

这两个是**按定位估的**，不是社区共识值。玩法面板或攻略站给出明确倍率后，直接改 JSON 即可，评分会立刻按新权重重算（不需要重新同步，`rescoreSnapshot` 会在读快照时重算）。
